# Privacy Policy

Olive Model Optimization runs the bundled MCP server locally. It does not collect or sell personal information.

Some optional tools can access external services when you request live documentation, GitHub issue data, Hugging Face model metadata, or a configured local Olive Studio endpoint. Those requests are made only to fulfill the requested operation and are governed by the privacy policies of the services you choose to use.

The server may process model paths, recipe data, and error messages locally to produce results. Do not include secrets, access tokens, or personal information in requests unless required by the service you are intentionally using.

For privacy questions, open a support issue in the repository: https://github.com/tonythethompson/olive-model-optimization/issues
